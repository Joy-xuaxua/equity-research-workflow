# 估值方法

目标：用**至少三种适用**方法给出合理价值区间（适用方法不足三种时如实写明哪些被闸门剔除、为什么），按第 8 节规则合成综合区间并算出相对现价的隐含空间。多方法的意义在于交叉验证——区间相近则结论更可信；分歧大要解释为什么（通常是增长/盈利假设、资本强度或折现率差异），采信哪个由预注册权重决定，不临场挑选。

原则：
- **事实由脚本生成，假设只给驱动，区间按第 8 节合成**：事实层由 `scripts/valuation_inputs.py` 写入 `valuation/inputs.json`（改事实走 override 协议）；判断层 `valuation/assumptions.json`（`"schema": 3`）只放驱动参数，每个驱动标锚、分位、证据——规则唯一来源是 `valuation-assumptions.md`（参数卡），本文件只讲方法学与合成规则。
- 每种方法**显式列出关键假设**，假设比小数点重要；关键假设旁标注 base rate 分位（见 `base-rates.md`）。
- **所有 DCF/EPV/EVA/蒙特卡洛计算一律用 `scripts/dcf.py` 执行，禁止心算**。假设以 JSON 落盘，本身就是留档。
- 折现率全报告同源同值，构建方法见 `cost-of-capital.md`；风险只惩罚一次（折现率或情景概率，二选一）。
- 估值是区间不是点；结论标签由第 9 节的预注册规则映射产出，不允许临场发挥。
- **估值前置条件**：财报可信度等级（`forensic-accounting.md`）为 C/D 时，估值让位于可信度问题。

## 1. 相对估值（可比公司 + 历史区间 + 合理倍数）

常用倍数按公司类型选择：P/E（盈利稳定）、EV/EBITDA（重资产/资本结构差异大）、P/S（未盈利成长）、PEG（粗略）、EV/ARR（订阅）、P/B–ROE（金融）。

做法：
1. 公司自身**历史倍数区间**（近 5–10 年 25/50/75 分位），看当前位置。
2. 3–6 家**可比公司**同一倍数对比（A股/港股对照系见 `markets-cn-hk.md` 第 6 节）。
3. **合理倍数（warranted multiple）纪律**：不许直接抄同业中位数。倍数是增长 g、回报 ROIC、风险 r 的函数——稳态下合理 P/E ≈ (1 − g/ROIIC)/(r − g)。先算公司基本面对应的合理倍数，再与市场给的倍数比较；差额要么是市场错（机会），要么是你没看到的风险（警报），显式归因。
4. "合理倍数 × 对应财务指标" = 每股合理价值的对照。进综合区间的倍数区间由脚本从逐家同业原始倍数或自身历史序列算分位（第 7 节 `multiples` 块）；合理倍数用于与市场倍数对照、归因差额，不直接手设区间。

| 倍数 | 当前 | 自身历史中枢 | 可比中位 | 合理倍数(算式) | 选用 | 隐含每股价值 |
|---|---|---|---|---|---|---|

## 2. 绝对估值：DCF（驱动式 FCFF）+ 终值纪律

全部路径由脚本按驱动参数逐情景生成，**不手填营收/FCF 率路径**（schema 3 写 `revenue`/`fcf_margin` 即硬错）。驱动的默认值、锚、三情景规则与偏离要求见 `valuation-assumptions.md` §1。

模型（逐情景，金额为千元报表币）：

```text
d        = 0.5^(1/half_life)
g_1      = g1
g_t      = g∞ + (g2 − g∞)×(d^(t−2) − d^(N−2))/(1 − d^(N−2))      t = 2..N（第 N 年恰好 = g∞）
Rev_t    = Rev_{t−1}×(1 + g_t)，Rev_0 = base_revenue
m_t      = m1 + (margin_target − m1)×min((t−1)/margin_years, 1)
NOPAT_t  = Rev_t×m_t×(1 − tax)；EBIT≤0 的年份不交税并累积 NOL，之后盈利先抵扣
Reinv_t  = ΔRev_t / S2C，下限 0（allow_capital_release 时可为负，累计释放 ≤ IC_0）
FCFF_t   = NOPAT_t − Reinv_t
TV       = NOPAT_{N+1}×(1 − g∞/ROIIC∞)/(WACC − g∞)
           NOPAT_{N+1}≤0 时不计 (1 − g∞/ROIIC∞) 项，标"终值期仍亏损"
每股     = (EV − net_debt + pro_forma 现金)×1000 ÷ fx ÷ (shares_outstanding×(1 + dilution)^N)
```

关键驱动（必须列出，附 base rate 分位）：g1 / g2 / half_life / horizon、m1 / margin_target / margin_years、sales_to_capital、tax、WACC（见 `cost-of-capital.md`）、永续 g（≤ rf，硬校验）、ROIIC∞、dilution。脚本输出逐年路径表（增速、营收、利润率、NOPAT、再投资、FCFF、ROIC）、EV、TV 占比、退出 EV/NOPAT、5/10 年营收 CAGR、终值再投资率与每股值。

**终值纪律（终值合理性三查）**：
1. 隐含退出倍数（脚本输出退出 EV/NOPAT）≤ 成熟同业当前倍数，超出须论证。
2. 终值占总价值 > 80%（脚本标 ⚠TV>80%）→ 说明显式期太短或市场在买遥远故事，明示。
3. **增量回报向资本成本收敛——脚本默认实现**：`terminal.roiic` 缺省即 ROIIC∞＝WACC，此时 TV＝NOPAT_{N+1}/WACC（增长不再增值，永续期价值≈EPV 式零增长价值）。要在终值里保留超额回报，须给 `terminal.roiic`（或情景 `roiic`）> WACC 并写 `roiic_reason`（ch3 护城河"宽"＋CAP 论证）；上限 WACC+5pp，脚本硬校验。历史上超额回报期 >15–20 年的公司极少（`base-rates.md` 第 4 节）。

执行：`scripts/valuation_inputs.py <workdir>` → `valuation/inputs.json`；写判断层 → `scripts/dcf.py --inputs valuation/inputs.json --config valuation/assumptions.json`。

**敏感性（脚本自动输出，基准情景每股）** ⚑：WACC×margin_target 必做；成长股（基准 g1≥15%，或写 `sensitivity_growth: true`）加 g1×margin_target；ROIIC∞≠WACC 时加 WACC×g。原因：ROIIC∞＝WACC 时 TV＝NOPAT_{N+1}/WACC，g 不影响价值，WACC×g 表在 g 方向是平的（脚本省略并注明）。另输出**驱动龙卷风**：基准情景各驱动按一档扰动、按 Δ每股值排序，前 3 个（★最承重）即 thesis brief 的"最承重假设"。

## 3. 三要素估值法：资产重置 · EPV · franchise 成长（Graham–Greenwald）

（方法学不变，与旧版一致；与本手册其他方法冲突时以 Greenwald 原著为准。）

**第一层 · 资产重置价值（底价）**：资产负债表逐项挤水分减总负债（脚本执行走第 7 节 `sum_of_parts` 的 `asset_ladder`，受变现路径闸门约束）。折扣参考：现金 100%、证券 95–100%、应收 80–90%、存货（原料/成品）80–90%/50–70%、设备 20–30%、厂房 40–60%、地产按市价、商誉多按 0。

**第二层 · EPV（核心）**：`EPV = 常态化盈利 ÷ 资本成本`（零增长永续）。常态化盈利剔非经常、加回超维持性 capex 的 growth capex；默认 NOPAT 口径（÷WACC 得 EV，减净债加过剩现金得权益）；数据不足退净利润口径（coc 视作权益成本）。资本成本与 DCF 的 WACC 同源。**护城河财务验证**：EPV/调整后净资产的多年趋势——≈1 无护城河、<1 毁灭价值、≫1 且长期稳定 = 护城河的财务度量；与第三章定性评分交叉印证。

**第三层 · 成长价值（仅护城河内计）**：`价值 = E×(1 − g/ROIIC)/(coc − g)`，要求 ROIIC>coc 且 g<coc；否则退简化式 EPV×(1+保守 g)。保守 g = 历史 5 年利润 CAGR 与宏观锚取低。schema 3 不单列此层：成长价值由第 2 节 DCF（ROIIC∞）与第 4 节 PVGO 体现。

执行：`methods.epv` 块（默认启用，写 `"epv": false` 关闭）。脚本默认算常态化 NOPAT＝近 5 年经营利润率中位 × 基期营收（＋`adjustments[] {item, amount, source}`，逐项引用出处）× (1−t)；EPV 权益＝NOPAT/WACC − 净债；区间 lo / mid / hi＝WACC+1pp / WACC / WACC−1pp。常态化 NOPAT≤0，或行业 `fcff_applicable=false` → 闸门剔除。脚本同时输出 EPV 权益/账面权益与护城河判定。

## 4. 反向 DCF + PVGO 分解——预期差分析主线（第一章开篇框架）

反向 DCF 问"**现价假设了什么**"，是整份报告的分析主线（完整方法论见 `expectations-investing.md`）。

- **反向 DCF（脚本自动，无需配置块）**：interim＝基准情景前 5 年 FCFF；稳态 FCF 率＝margin_target×(1−t)×(1−g/ROIIC)，取基准、牛两档。由现价解出稳态首年所需 FCF → 所需营收与隐含 5 年营收 CAGR，并与基准路径 5 年 CAGR 并列。所需 FCF≤0（现价已被建设期 FCFF 覆盖）或稳态 FCF 率≤0 时，脚本输出说明或"不适用"。
- **PVGO（脚本自动）**：`现价 = E/r（零增长价值） + PVGO`，E＝常态化每股 NOPAT（与 EPV 同口径），r＝WACC；输出**现价中为未来增长付费的百分比**。E≤0 时输出"PVGO 不适用"。PVGO 占比 >50% 的标的，报告必须回答"这些增长从哪来、谁买单"。
- 反向 DCF 与 PVGO 是证伪现价的框架，**不进综合区间**。
- 呈现：把隐含要求翻译成参照系（对照 base rates："隐含连续 N 年 Y% 增速，历史上做到的公司占 Z%"）。结论句式："市场不是在给 × 定价，而是在给 × 定价"。
- 产出**预期差 Gap 表**（骨架见 `expectations-investing.md` 第 2 节），置于报告第一章。

## 5. 情景加权公允价值 + 蒙特卡洛

**三情景（必做）**：熊/基准/牛各为一套内部自洽假设（不是基准 ±20%）；熊市要问"理性管理层届时会怎么做"。概率规则见 `valuation-assumptions.md` §3（默认 0.25/0.50/0.25，每个情景 ≥0.15，和为 1；偏离默认写 `prob_reason`）；脚本一次完成加权。每个情景必须标注**当前证据强度**（弱/中/中强/强）与证据来源。若 bull 或 bear 情景已有中强/强证据（例如最新财报 KPI、利润率同升、订单/积压、价格反应或监管进展）支持，不能只给尾部概率；必须提高概率，或显式解释为什么该证据尚不足以改变概率。

**稳健性检验（脚本固定扰动集，不自选组合）**：概率——基准挪 0.15 给熊 / 给牛；主方法权重 ±0.1（适用方法 ≥2 种时）；WACC ±1pp；S2C ±30%；margin_target ±2pp ⚑。每组重算 [L, H] 与标签，输出"标签翻转 k/n"；扰动后无法求值的组标"不适用"。有翻转时如实写"结论对 X 敏感"并写明翻转条件。

**蒙特卡洛（情景混合抽样，默认运行，写 `"montecarlo": false` 关闭）**：先按情景概率抽情景，再在相邻情景驱动的中点之间均匀扰动 g1/g2/margin_target/S2C/half_life（端点情景向外对称延伸），WACC ±0.5pp；固定种子（默认 n=2000、seed=42）。输出 P10/P25/P50/P75/P90、均值与 **P(内在价值 < 现价)（即"现价买入是错误"的概率）**。蒙特卡洛只看分布形状与 P(loss)，**不进综合区间**，不替代三情景。

**市场再定价提示**：情景价值回答"最终值多少钱"，不自动回答"市场接下来先交易什么"。当最新财报或事件刚改变核心变量时，须另写未来 1–3 个月市场交易方向：市场更可能先交易收入/订单加速、利润率、capex 回报、监管风险、回购变化，还是估值均值回归。该判断进入第一章决策三分法，不改变内在价值标签，但会影响动作节奏。

## 6. EVA——DCF 的经济利润分解（不进区间）

`EVA_t = NOPAT_t − WACC × IC_{t−1}`；同一驱动路径下 `EV = IC_0 + PV(显性期 EVA) + PV(终值期 EVA) ≡ DCF`（脚本逐情景断言恒等，容差 1e-6）。因为与 DCF 恒等，EVA 不是独立方法：**不进综合区间，也不算"交叉验证"**。

为什么仍要看：把价值拆成"存量资本 + 超额回报"，暴露两个只看 DCF 总额时看不见的问题——
1. **公司现在到底赚不赚超过资本成本的钱**（EVA 连年为负的"增长股"是价值粉碎机）；
2. **增长与再投资是否自洽**：`内生增长 g = 再投资率 RR × ROIIC`——想要 10% 增长、ROIIC 只有 12%，意味着要再投 83% 的利润，FCF 所剩无几。驱动模型里再投资＝ΔRev/S2C，脚本打印逐年隐含 ROIC 与终值再投资率（g∞/ROIIC∞），据此检查 g＝RR×ROIIC 是否合理。

执行：无需单独配置块，脚本逐情景输出分解。金融股用剩余收益的权益版（净利润 − CoE×净资产），仍是银行/保险的主力绝对估值法，可作为独立方法——以第 7 节 `custom` 登记（`valuation/calc/`；其驱动模型列为后续）。

## 7. 其他适用方法（multiples / sum_of_parts / custom）

三种配置块写在 `methods` 下，各自输出每股 [lo, mid, hi]（价格币）；字段细则见 `valuation-assumptions.md` §2。

| 块 | 用途 | mid | lo / hi | 闸门 |
|---|---|---|---|---|
| `multiples` | 相对估值（第 1 节） | 合成倍数 P50 × 指标（EV 口径再减净债） | P25 / P75 | 指标 ≤0 或观测 <3 → 该倍数剔除；全部剔除 → 方法剔除 |
| `sum_of_parts` | SOTP / REIT NAV / 资产梯 / 清算 | 各部件 mid 之和 − 扣减 | 各部件 lo / hi 之和（资产梯：压力折扣 / 有序折扣） | 资产梯、清算无 `realization_path` → 只作信号 |
| `custom` | rNPV、矿山 NAV 等脚本外计算 | calc 输出 | calc 输出 | 须为 `valuation/calc/*.py`；非行业主方法权重上限 0.25 |

- **multiples**：只接受逐家同业原始倍数 `{name, value, source}`（≥3 家）或自身历史倍数序列（≥3 期），由脚本算 P25/P50/P75；**不接受经验带**（写 `band` 硬错）⚑。同一方法下多个倍数先等权插值中位数合成，整体算一票。脚本同时打印合理倍数（P/E：(1−g/ROIIC)/(r−g)；P/B：(ROE−g)/(CoE−g)）与市场倍数对照。
- **sum_of_parts**：部件类型 `value` / `metric_x_multiple` / `metric_div_rate`，每个部件带 `source`；SOTP/NAV 默认扣净债。SOTP 与 DCF 的分歧＝市场情绪的定量化；平台/集团必做。
- **资产法变现路径闸门** ⚑：`asset_ladder` / `liquidation` 只有在 `realization_path {evidence, source}` 有公告证据（控制权变更、处置、回购/分红政策、清算程序）时才进区间；否则只作"资产底价（少数股东不可实现）"信号输出。
- **custom**：脚本覆盖不到的计算只能放 `valuation/calc/<name>.py`，输出写同名 `.txt` 并含 `RESULT lo=… mid=… hi=…`（每股，价格币）。
- **行业特定**：NAV（矿业/航运/地产）、rNPV（医药管线）、P/EV（保险）、P/AFFO（REIT）、中周期盈利法（周期股，通用规则：中周期 EPS = 10 年利润率带宽中点 × 当前收入；禁止峰值×峰值）——按上表选块；行业主方法见 `industry-rules.json` 的 `valuation.primary`。
- **Morningstar 公允价值**：第三方锚，标日期/星级/不确定性；区分分析师 FV 与量化评级；只作参照，不进区间。

## 8. 综合区间合成与 Football Field（脚本按规则计算，不手填）

① **每种适用方法给每股 [lo, mid, hi]**（口径见第 2、3、7 节）。反向 DCF、PVGO、EVA、蒙特卡洛不进区间。
② **闸门**（脚本强制，清单见 `valuation-assumptions.md` §4）：行业 `fcff_applicable=false` → dcf、epv 关闭；基准情景每股 ≤0 → dcf 关闭，标"经营价值为负"；常态化 NOPAT ≤0 → epv 关闭；倍数指标 ≤0 或观测 <3 → 该倍数关闭；资产梯/清算无变现路径 → 只作信号。被剔除的方法权重为 0。
③ **权重**：行业主方法 0.5，其余适用方法均分；主方法被剔除时所有适用方法等权。`weights.adjust` 每项 |Δ| ≤0.1（超限硬错）并在 `weights.reasons` 写理由，调整后归一；非主方法的 custom 上限 0.25。
④ **插值加权中位数**：L＝各方法 lo 的加权中位数，H＝各方法 hi 的加权中位数。按值排序，每个值位于其累计权重区间的中点，在 0.5 处线性插值——对权重连续，小幅调权不跳变。极少数权重组合下两侧各自排序会得出 L>H，此时脚本回退为按 mid 排序、用同一组插值系数同时作用于 lo/hi，保证 L≤H，并在 ⚑ 标记行注明"合成口径回退"。
⑤ **诊断**（脚本输出交集、包络、mid 最大/最小）：
   - **方法分歧**：交集为空，或 mid 最大/最小 >2× → 章节须逐项归因（增长、利润率、资本强度、折现率还是口径），不许静默取平均；
   - **单一方法**：只剩一种适用方法；
   - **经营价值为负**：基准情景每股 ≤0（强信号，保留输出）。

   任一标记出现 → 不确定性 ≥"高"（第 9 节）。
⑥ **H≤0，或全部方法被闸门剔除** → 标定行为 `=== 标定 === 无法给出可靠估值区间（原因）`，章节如实写明缺什么，不自拟区间。

呈现：方法区间表（lo / mid / hi / 权重 / 闸门）、合成与诊断、football field 均由 `dcf.py` 输出，**原样粘贴**，不重画、不改数（见 `output-format.md` 第 4 节）；另用一句话说明主方法与权重调整理由。

## 9. 结论标定与仓位思维（预注册，不得临场发挥）

**估值标签**（综合区间 [L, H]，现价 P，±15% 缓冲带）：

| 条件 | 标签 |
|---|---|
| P < 0.50L | 显著低估 |
| 0.50L ≤ P < 0.85L | 低估 |
| 0.85L ≤ P ≤ 1.15H | 合理 |
| 1.15H < P ≤ 1.50H | 高估 |
| P > 1.50H | 显著高估 |

**动作矩阵**（标签 × 不确定性；不确定性优先 Morningstar 评级，缺失自评并写依据；第 8 节出现方法分歧 / 单一方法 / 经营价值为负任一标记时，不确定性至少取"高"）：

| 标签 \ 不确定性 | 低 / 中 | 高 / 极高 |
|---|---|---|
| 显著低估 | 买入 | 分批买入（P < 0.70L 方可首建） |
| 低估 | 买入/分批买入 | 小仓位试探或等待 |
| 合理 | 观望（持有者持有） | 观望 |
| 高估 | 减持/规避 | 规避 |
| 显著高估 | 规避，持有者减持 | 同左；默认不建议做空 |

**无法给出可靠估值区间**（第 8 节 ⑥）：不套标签表、不写综合区间与隐含空间；动作不经标签映射，只按财报可信度等级与下方否决项给出，并说明"估值不可靠"本身是动作依据。

**否决项（一票降级）**：治理红旗 ≥2 项严重级或**财报可信度 C** → 动作最高"观望"；**可信度 D** → 规避；护城河"无"且标签高估 → 直接规避。双重上市按 `markets-cn-hk.md` 分市场标定。

**动作节奏修正**：动作矩阵给出价值纪律下的默认动作；若未来 1–3 个月市场交易方向与价值标签相反（如内在价值"合理/偏贵"，但财报后再定价方向"偏上"），不得简单写"观望"了事。必须明确是"等待回调"、"持有不追"、"突破/回调触发复核"或"小仓位跟踪"，并给触发条件。

**仓位思维（`position` 块，给动作配量级）**：
- 期望收益 `EV = Σ p_i × (V_i/P − 1)`（用三情景的每股价值与概率）。
- **不对称比 = 上行空间 ÷ 下行空间**（牛情景涨幅 ÷ 熊情景跌幅）；<1.5 的"低估"多半不值得建仓。
- Kelly-lite 参考仓位 = ¼ × Kelly 分数（脚本按两点近似计算），仅作量级参考、上限 15%，**不构成配置建议**——报告只说"该赔率结构支持 小/中/标准 仓位"。
- 亏损概率 P(loss)（蒙特卡洛可得）与最大可容忍下行一并呈现。

**一致性要求**：第一章与第九章的标签、动作、预期差方向必须与本规则可复算地一致；schema 3 下 `dcf.py` 由合成区间直接输出标定行（旧 schema 配置仍按 range_low/range_high 输出），`check_research_output.py` 读 `inputs.json` 重算区间，复核报告标签与文本一致性。
