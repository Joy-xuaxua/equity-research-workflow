# 数据需求清单（W1 各线采集义务）

## 0. 使用说明

- 二分定位：**WHERE**（去哪采、Tier 1–5 与降级路径）＝`data-sources.md`；**WHAT**（采什么、口径如何）＝本文件。
- 清单语义：**进了本清单＝都要采**。未取到一律落「未获取到」表并在回报列为缺口，不静默跳过、不在采集端按主观重要性分级取舍；缺口的严重性由下游机械判定（检查器降级、脚本缺口检测、W2 升级项），无需采集端预判。
- 读法：按本线 (mode, line) 直达 §1–§4 中唯一对应小节；`ah_listing=true` 或 `cn_adr=true` 加读 §5；`industry` 已知加读 §6。§7 为维护索引（消费方×线对照），采集时不必读。
- 纪律不变：Tier 1–5 优先级与降级、原文引用协议（逐字＋时间戳）、「未获取到」表、绝不阻塞——本清单不改变任何采集与降级纪律。

## 1. 线 01 披露（full：01-disclosure｜earnings：01-disclosure）

### 1.1 台账供数（逐年精确序列）

财年深度：full ≥5 个完整财年；earnings 持续覆盖 ≥4 个季度、首次 ≥3 财年＋8 个季度。M-Score 分量（PP&E／流动资产／折旧摊销／sga）需 t 与 t−1 两年序列（最小列集以 `forensic-accounting.md` §7 为准）。

**损益与费用**

| 数据项 | 采集与口径要点 |
|---|---|
| 营业收入／毛利／经营利润／税前利润／净利润／EPS | 主表＋分部附注；持续经营 vs 年内损益口径注明 |
| 销售及营销＋一般及行政（sga 口径） | 损益表／费用附注拆分，研发单列 |
| 研发费用（损益表行） | 研发费用率分子；非资本化口径 |
| 股份支付 SBC 绝对额（逐年） | 现金流量表补充资料或股份支付附注；Non-GAAP 桥原料 |

**资产负债表**

| 数据项 | 采集与口径要点 |
|---|---|
| 总资产／总负债／所有者权益 | 同一期末时点（BS 恒等式勾稽） |
| 应收账款净额（贸易应收） | 净额口径；拨备前后口径注明 |
| **固定资产 PP&E（原值与净值）** | PP&E 附注——年报已下载也须抽附注 |
| **流动资产合计** | 资产负债表行 |
| **折旧摊销** | 现金流量表补充资料或折旧附注；含／不含摊销注明 |
| 现金及现金等价物 | 受限现金与可自由支配短期投资单列 |
| 有息负债合计 | 短＋长借款、租赁负债、应付债券；**勿只采净额**（net_debt 由估值端两端相减） |
| 合同负债（流动／非流动拆分）／少数股东权益／商誉 | 递延收入背离与 EV 桥原料 |

**现金流与股本**

| 数据项 | 采集与口径要点 |
|---|---|
| CFO／资本开支／公司自定义 FCF | 自定义 FCF 口径注明（fcf==cfo−capex 勾稽） |
| 加权平均股数（IAS 33）与期末总股本 | ⚠ 两个概念分开采（可差数倍） |
| 员工数（期末正式雇员） | 人均创收分母；年报人力资源节 |
| 存货细分（原材料 vs 产成品）／应付账款及票据 | 应计分解（应收/存货/应付各贡献多少）；无存货的公司记「不适用」，不入「未获取到」 |

### 1.2 财报质量证据（五项检查原料）

| 数据项 | 采集与口径要点 |
|---|---|
| 收入确认政策关键句（时点/履约、长合同 POC、经销商、bill-and-hold） | 会计政策附注摘录 |
| Non-GAAP 调整逐项（金额＋性质） | 调整经常性判定；GAAP 对账表 |
| 审计师身份／审计费／任期／审计意见类型 | 年报审计报告节 |
| 关键审计事项（KAM）原文 | 逐字摘录 |
| 应收账龄表（分档） | 应收附注；与 DSO 背离互证 |
| 季度收入分布（Q4 占比）或季度序列 | 季末突击发货红旗 |
| 拨备／坏账计提率序列 | 应收拨备附注 |
| 资本化开发支出/软件/客户获取成本明细与政策 | 无形资产附注，与费用化对比 |
| 关联交易附注逐项（科目＋金额＋对手方＋定价） | 关联方附注 |
| CFO/财务负责人/审计委员会更迭 | 公告与年报治理节 |
| 持续经营措辞／重述与会计政策变更史 | 审计报告与附注 |
| 监管函件/交易所问询（主题＋频率）／做空报告指控与回应 | 问询函回复公告；指控与回应并列 |
| 董监高持股/薪酬/任期明细 | 代理声明／年报董监高节／权益披露 |

### 1.3 章节原料

| 数据项 | 采集与口径要点 |
|---|---|
| 分部收入三维度（业务线/地区/客户，各含同比） | 分部报告附注，三维度各含同比 |

### 1.4 仅 earnings：本季供数与指引全维度

| 数据项 | 采集与口径要点 |
|---|---|

| 上期指引原文（新旧桥基准） | 与新指引同维度对照 |

## 2. 线 02（full：02-market 行情估值锚｜earnings：02-consensus 预期线）

### 2.1 full 模式：行情、股本与估值锚

| 数据项 | 采集与口径要点 |
|---|---|
| 基准三元组：现价 × 期末总股本 = 总市值（同源同时点） | 三项同源同时点采齐；注明交易所、币种、收盘时点 |
| 52 周最高**与最低** | 最高与最低都要采 |
| 关键倍数 TTM（PE/PS＋行业主倍数） | 行业主倍数（EV/Revenue、EV/ARR 等）按附录口径 |
| **WACC 输入①无风险利率** | 估值币种对应 10 年期国债收益率，当日值。四项公共纪律：各带值、来源/Tier、URL、时间戳；采不到落「未获取到」（已尝试＋原因），禁止沿用记忆值或训练先验充当；估值 agent 无网络，本线是唯一通道（构建需求见 cost-of-capital.md §1，取数来源见 data-sources.md §2.4） |
| **WACC 输入②ERP（股权风险溢价）** | Damodaran 当月隐含 ERP＋国别风险溢价，按业务地域收入加权（非上市地） |
| **WACC 输入③行业无杠杆 beta** | 按 G1 主行业附录选定行业 |
| **WACC 输入④币种间即期汇率** | 估值币种↔报表币种↔可比口径币种，当日 |
| **peer 倍数＋分母**（3–6 家） | peer 的收入/ARR/订阅额等分母至少覆盖行业附录主倍数所需，与倍数同期间、同币种、注明口径（GAAP/Non-GAAP、财年错位）；只有倍数快照而无分母＝未获取到，禁止用标的自身分母冒充 peer 分母 |
| 自身历史倍数区间（5–10 年 25/50/75 分位原料） | 历史价格序列＋历史财务 |
| 港股流动性结构（仅港股标的：指数纳入/剔除、互联互通资格与南向持仓及资金流、沽空额与比率、解禁日历与流通盘锁定） | 催化剂与流动性折价原料；不依赖 ah_listing 触发，纯 H 股同样适用；非港股标的记「不适用」不入「未获取到」 |
| 股息率／回购收益率 | |
| Morningstar FV/星级/护城河/不确定性 | 标发布日期；见 data-sources.md §4.1 |

### 2.2 earnings 模式：预期线

| 数据项 | 采集与口径要点 |
|---|---|
| 财报**前**一致预期（收入/EPS 分维度） | 财报后修订不得冒充财报前共识 |
| **共识覆盖统计**（分析师家数/均值中位数口径/统计日期） | 只报数不报口径不可用 |
