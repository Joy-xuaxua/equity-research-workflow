# 数据需求清单（W1 各线采集义务 → 下游消费对照）

> **防漂移（先读）**：本文件不复制任何注册表——「指标登记」块的合法 key／单位／期间以 `collision-metrics.json` 为准；派生指标与外部输入 schema 以 `derived-metrics.json` 为准；行业必查 KPI 以 `industry-rules.json`＋`industries/<slug>.md` §4 为准；financials.csv 列名与深度以 W2 对账契约（对账 agent 动作 5）为准、M-Score 最小列集以 `forensic-accounting.md` §7 为准。本文件大量条目**不在登记清单内**（如 52 周低点、应收账龄、共识覆盖统计）：一律写入「发现」节，仍遵守「清单外指标不登记」。本文件与上述权威不一致时，以权威为准并回报编排者。

## 0. 使用说明

- 三分定位：**WHERE**（去哪采、Tier 1–5 与降级路径）＝`data-sources.md`；**WHAT**（采什么、优先级、下游谁消费）＝本文件；**登记**（哪些 key 进「指标登记」块）＝`collision-metrics.json`。
- 消费方代号：`W2→CSV`（financials.csv 供数）｜`W2→ledger`（行情股本基准节）｜`W2→派生`（derived-inputs.json 外部输入原料）｜`W3→应计/M-Score/收入确认/资本化/治理`（五项检查）｜`W4-ch2…ch8`（对应章节）｜`W5→WACC`｜`W5→锚`（估值输入）｜`W7→快照`（结论章 Tearsheet）｜`G1`（编排门禁）。W6 红队自带联网反证、W8 交付不消费原始采集数据，故本表无其行。
- 优先级：**必采**＝下游硬依赖，缺失会触发脚本降级／章节缺口／估值走简化档（例：M-Score 四列、WACC 四项、共识覆盖统计）；**应采**＝正常应有，缺失走「未获取到」并通常触发补采；**可选**＝增强锚，缺失不算关键缺口。
- 读法：按本线 (mode, line) 直达 §1–§4 中唯一对应小节；`ah_listing=true` 或 `cn_adr=true` 加读 §5；`industry` 已知加读 §6。§7 为维护索引，采集时不必读。
- 纪律不变：Tier 1–5 优先级与降级、原文引用协议（逐字＋时间戳）、「未获取到」表、绝不阻塞、「清单外指标不登记」——本清单只扩大「发现」节的采集范围，不改变任何登记与降级纪律。

财年深度：full ≥5 个完整财年；earnings 持续覆盖 ≥4 个季度、首次 ≥3 财年＋8 个季度。列名与深度以 W2 对账契约为准，本节只给采集口径。
