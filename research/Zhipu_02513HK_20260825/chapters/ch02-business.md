## 二、业务详情

本章要点：智谱（Z.AI）是"自研通用基座大模型 + MaaS 开放平台"公司，FY2025 收入 7.24 亿元人民币（+131.9%），本地化部署占 73.7%（+102.3%）、云端部署（数值上＝开放平台及 API 产品线）占 26.3%（+292.6%，最快引擎），产品线中企业级智能体 +248.8% 次之。按 SaaS 框架衡量其"订阅纯度"偏低——92.2% 收入于客户验收时点一次性确认、合同负债/收入仅 20.5%、NRR 与 RPO 未披露——增长质量的可验证证据目前不足（见 2.4；收入确认红旗详见第五章）。

> 单位与口径：除注明外，财务数字为人民币（表格单位见表头，千元＝forensic 台账原值），行情与募资为港元。财务截至 FY2025（2025-12-31，KPMG 审计）；台账与对账基准 2026-08-25。带 ▶ 标记的指标为对账裁决口径（双值/悬置），不得只取单值。

### 2.1 商业模式：一条公式、两条变现路径

智谱 2019-06 成立为有限责任公司，2025-03 改制为股份有限公司，2026-01-08 以 18C 特专科技章在联交所主板上市（H 股架构、非 VIE、无 ADR）；英文名 2026-07-14 起变更为 Z.AI Co., Ltd.（Tier 1，reconciled/01 A 节）。按 Frost & Sullivan（招股书承载的第三方估算），2024 年公司按收入在中国通用大模型开发商中排名第二（独立厂商第一，仅次于科大讯飞），份额 6.6%。

管理层把商业模式压缩为一句公式：「AGI 商业价值＝智能上界×Token 消耗规模」（FY2025 业绩公告 MD&A，2026-03-31，Tier 2）。前半句对应基座模型能力投资，后半句对应 Token 消耗的变现，落地为两条路径：

- **云端部署（FY2025 占 26.3%）**：MaaS 开放平台 BigModel.cn 的 API 用量计费＋GLM Coding Plan / Claw Plan 订阅，接近云服务的用量经济；
- **本地化部署（FY2025 占 73.7%）**：企业级通用大模型与企业级智能体的项目制交付，于客户验收时点确认收入（IFRS 分部附注），接近软件项目交付经济。

我的判断：这不是纯 SaaS，而是"模型能力批发商"的混合体——云端部分可用 SaaS/云框架分析，本地化部分必须按项目制软件对待（两者毛利率 18.9% vs 48.8%、确认模式 时点 vs 随时间 均不同）；对整体收入套用单一 SaaS 倍数，会在结构上高估其经常性收入属性（依据：表 2-2/2-3 与 2.4 节 KPI 表）。

注（ARR 口径警示）：媒体转述的两个 ARR 数据点不能互洽——FY2025 末 MaaS API ARR 约 17 亿元（≈2.4 亿美元）大于 2026 年 1 月媒体口径 ARR 约 0.4 亿美元，且两者均无公司定义、无 Tier 1 披露。我的判断：该序列只能作方向性证据（爬坡陡峭），不得进入定量模型；卖方对 2026 年底 ARR 的预测亦为 ▶双值@C08（汇丰 20 亿美元·公司整体 ‖ 高盛 25 亿美元·API 业务，口径不同不可直比），引用须注明口径。

"订阅纯度"三个硬证据：①92.2% 的收入于某时点（客户验收）确认，随时间确认仅 7.8%；②合同负债（流动）/收入 20.5%（含非流动递延 45.4%），远低于预收驱动的订阅软件；③NRR、RPO、客户留存均未披露。这是本章对增长质量的核心保留——应收增速 +232.7% vs 收入 +131.9%（差 100.85pp）、KPMG 将本地化收入确认列为关键审计事项等财报质量红旗，详见第五章。

我的判断（行业附录必写结论句）：这家公司当前价值最依赖的不是本季度收入，而是未来数年能否在毛利率企稳（当前 41.0%、云端仅 18.9%）的同时维持三位数增长（近三年 CAGR 约 +232%）并把 FCF margin 从 -313% 收敛转正；而验证该路径所需的留存（NRR）、获客效率（CAC payback）与 SBC 稀释（当前 SBC/收入 77.1%）三项核心 KPI 均未披露——首个可验证节点是 2026-08-31 中期业绩。
