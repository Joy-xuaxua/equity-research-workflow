- 绝对增长真实：本期收入已达 FY2025 全年收入的 131.7%（＝953,892÷724,334），但仍只有标普口径预期的 53%（1−47.2%）——该单分析师预期相当于 FY2025 全年收入的 2.50 倍（＝18.078÷7.2433，倍数口径）。

- 转化率缺口是关键：业绩会披露 8 月 MaaS ARR ▶ 双值@ledger C21：约 16 亿美元（月度收入×12，财新折合约 108 亿元/年）‖超 20 亿美元（单周收入×52，管理层自贴「激进」标签），全部为 Tier 5 转述、未经审计，Tier 1 公告「ARR」零命中；对照 2026H1 确认收入年化 19.08 亿元（＝953,892×2），缺口 5.7 倍（quality §1）。8 月单月年化基数（月均约 9.5 亿元）约等于 H1 六个月报表收入总和（03 线推算，未经公司确认）。

**我的判断**：本期预期差的本质是「ARR 年化口径→IFRS 确认收入」的转化率预期差，叠加本地化主动收缩；不是需求端 miss——云端 API 分部 +2,735.7%、API 均价较年初 +约 101%（Q1 口径曾 +83%）、单位 token 推理成本较年初 −80%（Tier 2 MD&A 管理层口径），且 8 月 ARR（月×12）落入旧登记 15–22 亿美元区间并高于中金预期（reconciled/02 §5：中金 9-1「ARR 超该行预期」）。依据：上表分解＋C21 双口径＋缺口 5.7 倍。

### 2.6 三类归类判定与门槛结论

- **收入端：miss**（对两套财报前一致预期 −47.2%/−29.7%；对中金单一模型 in-line）。不存在「超低预期后的超预期」；分部层面云端 API 属真兑现（+2,735.7%，量价证据可验证）。
- **亏损端：对彭博预估为「真超预期」成分为主的 beat**（费用纪律可验证：SGA −28.7%、员工 −10.3%），但绝对额仍同比扩大 13.0%。
- **IFRS 亏损收窄 12.1% 与 EPS 收窄 25.0%：低质量改善**（一次性基数效应覆盖 142%＋股本 +171.0% 撑大分母）。
- **门槛结论**：收入门槛未被跨越（双双 miss，旧登记 R1 向下失效条件已触发，判定属第九章）；质量门槛（现金转化、递延先行指标）未验证或未达成；唯一被跨越的是 ARR 量级门槛（Tier 5 口径，落入旧登记区间且高于中金预期）。

**我的判断**：下一期预期差的关键变量是「ARR→确认收入」的月度转化轨迹与本地化收缩是否见底，而非收入总量对单一分析师口径的再次偏差——2026H2 标普口径预期 67.675 亿元（同源单分析师）隐含下半年对上半年 +609.3%（＝67.675÷9.5389−1），该口径同样未经样本复核，引用须谨慎。依据：2.2 转化率缺口 5.7 倍＋2.4 递延背离＋C16 双值警示（若误用 18.078 亿单值，miss 幅度被夸大 17pp）。

我的判断：本期利润率叙事的关键不是 −23.6pp 的毛利率（结构性、可解释），而是「亏损收窄 12.1%」由一次性基数效应构成、经调整口径实际扩大 12.1%——在 FCF 未披露下，约 25.3 亿元费用暂存区与减值计提方向是下期必须闭环的验证点；若以下任一触发，我会下调盈利质量与长期利润率假设：①中期报告明细显示预付款项/其他非流动资产具跨期费用资本化特征（预付算力对应服务期跨年且不摊销）；②应收账龄＞6 个月占比升破 20%（现 17.0%）且计提率再降；③SBC/收入回升至 20% 以上（现 9.0%）且伴随新的大额授予；④整体毛利率跌破 20%（云端 24.6% 的成本优势被价格竞争侵蚀）。

### 6.4 管理层可信度评估（与 quality 等级 C 对齐）

正面（可勾稽项）：量价→分部毛利率自洽——API 均价 +约 101% 与云端分部毛利率 −0.4%→24.6% 转正同向（C19）；「亏的钱主要亏在训练下一代模型」与研发开支 +33.6%、研发费用率 223.4%（derived/rd_revenue）方向一致；毛利率腰斩未回避、首次正面归因。

### 8.3 反向 DCF + PVGO：现价在定价什么（开篇框架）

脚本 `reverse`/`pvgo` 块输出（EV 448,070 百万元＝市值 476,851－备考净现金 28,784）：

- 参照系翻译（我的判断，分母并列〔修正轮 F-1 更新〕）：所需稳态收入 2,002–3,003 亿元/年＝**① 窄口径：Frost & Sullivan 中国 LLM 市场 2030F 全规模（1,011 亿元，不含应用/agent 层）的 2.0–3.0 倍**；**② 宽口径：中国 AI 整体市场 2030F 约 9,930 亿元（另源，Tier 5）的 20–30%**（辅注：AI Agent 中国 2025–30 CAGR 71.5%，Tier 5）——宽口径弱化「2–3 倍全市场」的修辞，但不改变路径违规本身；**③ 全球前沿实验室**：Anthropic ARR 自 5 月约 470 亿美元增至 **7 月约 650 亿美元**（CNBC 2026-08-17 转述官方，Tier 5）——隐含稳态收入＝其 7 月 run-rate 的 **0.45–0.68×**（5 月口径 0.63–0.94×；USD/CNY＝6.7828 中间价，ledger §1.1）；OpenAI run-rate（约 400 亿美元）的 0.74–1.11 倍。对照 base rates（经验基准率，Mauboussin/McKinsey 长期研究）：增速 >20%/年的公司 10 年后中位数回落至中个位数、能连续 10 年保持 20%+ 的占 1–3%——**隐含 208%–234% 在跨公司分布中已在可标定分布之外（>P99）**；上版（价 1,007）同口径为 186%–210%，现价上涨使隐含要求进一步抬升。
- **前沿类别并列说明（F-1，我的判断）**：「前沿实验室」类别 2023–26 已实证多年 200%+（Anthropic 自 $1B ARR 后约 10x/YoY），跨公司历史基准率对该新类别的外推力度有限——但「类别内有先例」与「本案属该类别」是两个命题：把智谱归入该类别所需的证据（可审计的全球化收入、审计口径 ARR）目前全部缺位（地区收入未披露、ARR 全 Tier 5），故 >P99 定位对全体上市公司分布照常成立，类别先例只作方向性参照、不作分位豁免。
- **PVGO 分解**：常态化每股盈利 -8.33 元（TTM 口径，§8.1）÷11% ＝ 零增长价值 **-75.73 元/股** → **现价的 107% 在为未来增长付费**（1,024.12＝-75.73＋PVGO 1,099.85）。PVGO>50% 的必答题：增长从哪来——API 用量×价格的量价齐升（Tier 1/2 已验证方向）沿 ARR 陡坡（Tier 5 未经审计）兑现；谁买单——后付费 API 客户与企业级智能体客户，其付款意愿的证据目前止于应收（DSO 148.5 天、时点确认 89.6%，quality §1）。

结论句式：**市场不是在给「中国 LLM 第一梯队的份额增长」定价，而是在给「终局年收入 2,000–3,000 亿元、约为整个中国 LLM 市场 2030F 规模（窄口径）2–3 倍／中国 AI 总盘（宽口径）20–30% 的路径」定价**——即使按管理层自贴「激进」标签的周×52 ARR 口径全额兑现，2026 年 run-rate 也只有约 136 亿元。
