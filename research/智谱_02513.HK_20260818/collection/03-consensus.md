### D. 管理层业绩会（2026-03-31，FY2025 年度业绩发布电话会）与指引

公司 IR 确认业绩发布安排：2026-03-31（星期二）公布 FY2025 全年业绩并举行业绩发布会（来源：智谱官网新闻页 https://www.zhipuai.cn/zh/news，Tier 2；转述见搜狐/新浪）。电话会关键内容（三家独立转述交叉：证券时报、Moomoo/观点网、华尔街见闻/量子位，均 Tier 5 但相互印证）：

- 战略框架（CEO 张鹏）："AGI时代的商业价值可以归结为一个简洁的公式：智能上界 × Token消耗规模。智能上界决定了定价权，Token消耗规模决定了价值体量。"
- 2026 年指引性关键词（CEO 张鹏）："过去一年，智谱的关键词叫作'智能上界'。进入2026年，我们的关键词叫作'Token量'。"
- 经营目标（CEO 张鹏）：希望 API 业务收入占比提升至一半（当前开放平台及 API 占收入 26.3%）。
- ARR（CEO 张鹏）："当前，智谱的MaaS平台ARR（年度经常性收入）约17亿元，在过去12个月提升60倍。"
- 提价与供需（CEO 张鹏）："首先我们承认最近确实存在算力供给的约束和瓶颈。但在整个市场环境中，基于算力提供API服务的厂商非常多，客户接受我们涨价并持续选择我们的服务，说明我们的模型能力确实领先。"及"定价权还是由我们的技术实力以及长期趋势所带来的领先地位决定的。"
- 需求展望（CEO 张鹏）："OpenClaw等新应用形态的诞生，以及设备级原生智能的预期，使得未来API和Token的消耗会呈现指数级增长。我们相信API ARR的增长是一个确定性的、长期性的趋势。"
- 算力瓶颈量化（管理层）："实际需求水平大约是目前支持的日均调用的1至2倍"；"如果算力供给能够进一步释放，我们认为无论是调用量还是收入规模都具备比较可观的放大空间。"
- 定价体系判断（管理层）："低端的标准化的低复杂度推理和问答，未来会走向低价甚至最终免费；而高复杂度、高可靠性的、真正能够解决生产力问题的高质量Token……这部分塔尖的Token会让提供方具备持续的定价权和议价能力。"
- 商业模式对标（CEO 张鹏）：商业化路径"更像Anthropic这样的厂商，通过持续提升模型的智能上界，在高价值场景中建立定价权"。
- 量价齐升可持续性（董秘 肖磊）："Token的量价齐升并非短期阶段性结果，而是由模型能力提升与需求侧变化共同驱动，且提升趋势具备延续性"；"这充分证明了当前阶段需求本质上还是由模型能力驱动的，而不是以价换量驱动的。"
- 新概念（公司层面，量子位转述）：首次提出 Token 架构力 TAC（Token Architect Capability）= 调用智能的量 × 智能的质量 × 转化为经济价值的效率。
- 里程碑披露（管理层）：从 GLM-4.5 到 GLM-4.7，模型迭代使 API 平台 ARR 提升 10 倍。

重要提示：公司未给出正式的全年收入/亏损数字指引；上述"关键词""API 收入占比一半""ARR 增长确定性趋势"为管理层定性指引，登记供预测复盘使用。
