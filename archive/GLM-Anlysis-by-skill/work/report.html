二、业务详情

本章要点：智谱是"政企私有化基本盘 + MaaS/编程增长引擎"的双轮结构；73.7% 收入来自高毛利但难规模化的本地化部署，资本市场真正定价的是 26.3% 的 API/MaaS 业务——2026 年后者已成主引擎。

商业模式：公司定位"中国版 Anthropic"——北京智谱华章科技股份有限公司，源于清华大学 KEG 实验室技术转化，2019 年成立，全栈 GLM 基座模型（语言/多模态/智能体），一端服务政企与大型企业私有化部署，一端通过开放平台 API 与 MaaS 连接开发者（付费开发者 24.2 万，注册企业及用户超 400 万，服务 218 个国家与地区；中国前十大互联网公司中 9 家深度调用 GLM——2025 年报披露口径）。

三、业务与竞争分析

本章要点：行业处于 token 消耗指数级扩张期（中国模型 Q1 全球周均 token 12.96 万亿、为美国 4.3 倍），但供给侧免费/地板价 API 泛滥；智谱的综合护城河判定为"窄"——编程场景品牌与开源生态真实，却按月可被侵蚀，且尚未获得财务验证（EPV 为负）。

行业空间与周期：大模型商业化从"讲故事"转入"ARR 考核"阶段（钛媒体 2026-07）。Anthropic 估值 9,650 亿美元（2026-05-28 H 轮 650 亿美元融资）、run-rate 收入超 470 亿美元（PS 约 20.5x）；OpenAI 估值 8,520 亿美元、2025 年收入约 130 亿美元（PS 约 65x）。中国市场：央国企/政务数字化采购指南直接催生国产大模型规模化采购（2025–2026）；竞争侧阿里、字节将 API 价格压至地板价甚至免费，独立厂商必须在编程/智能体等高价值场景证明不可替代性。

竞争格局（份额趋势按最新公开信息）： - 月之暗面（拟 2026H2 港 IPO，Pre-IPO 估值 350–500 亿美元）：Kimi K3（2.8 万亿参数）2026-07 发布，被 JPM 称"重新设定前沿模型估值"，ARR 3 月 1 亿→6 月 3 亿美元； - MiniMax（0100.HK，2026-01-09 上市）：市值约 3,883 亿港元；M3 强化 Coding+Agent；亦已启动回 A； - 阿里/字节/百度/腾讯：依托云与政企生态形成庞大模型收入盘，价格战主导者； - 海外：OpenAI（GPT-5.6+CodeX 生态）、Anthropic（Claude Opus 4.8，编程标杆）。

本章要点：五种方法全部指向同一方向——反向 DCF 显示现价需要 2032–2037 年仍以 27–32%/年复利增长至 2,712–3,390 亿元收入（≈400–500 亿美元，接近 Anthropic 当前 run-rate 的全球体量）；概率加权 DCF 公允价值 407 港元/股；综合区间 [220, 720] 港元，现价 1,203 港元 → 预注册标定：显著高估。所有计算由 scripts/dcf.py 执行（配置留档 valuation_zhipu.json，2026-08-18）。

折现率与口径：WACC=11.5%（港股中资高波动成长快速档 9–12% 上沿，标注为简化锚；业务在内地、报表人民币、上市港股），永续 g=4%（低于中国长期名义 GDP 5–6% 上限）；汇率 HKD/CNY=0.859、USD/CNY≈6.73（2026-08-16）。风险只在情景概率中惩罚一次，折现率不再叠加惩罚。股本 4.66 亿股，净现金约 45 亿元（估算，见 5.1）。

6.1 反向 DCF + PVGO（开篇框架：现价隐含什么）

scripts/dcf.py 输出：现价隐含稳态首年 FCF 678 亿元/年；@20% FCF 率需稳态收入 3,390 亿元（自 2031 年 640 亿元起此后 6 年隐含 CAGR 32%），@25% 需 2,712 亿元（CAGR 27%）。参照系：3,390 亿元 ≈ 503 亿美元，≈ Anthropic 2026 年 run-rate（470 亿美元）的全公司体量——即现价假设智谱在 2030 年代中期再造一个 Anthropic 的收入规模，且此后仍以 27–32% 复利。PVGO 分解：每股常态化盈利 -10.1 元（2025 经调整口径摊薄估算）÷ 11.5% = 零增长价值 -87.8 元 → 现价的 109% 在为未来增长付费（PVGO>50% 红线，本报告已在 Gap 表回答"增长从哪来、谁买单"：coding 订阅×政企采购×token 通胀，买单者为全球开发者与央国企预算）。

6.3 三要素/EPV（盈利能力价值）

EPV = 常态化 NOPAT -32 亿元 ÷ 11.5% = 权益价值 -233 亿元 → 每股 -50 元（约 -58 港元）；EPV/净资产无法给出有效倍数（净资产为负）→ 按 Greenwald 判定：当前处于价值毁灭区（ROIC<资本成本）。资产重置底价：现金 22.59 亿元（2025 年末）+GPU/其他资产（未获取到明细）→ 现金底价每股 4.94 元（约 5.7 港元）。买点阶梯：底价 5.7 港元 << EPV 0 << 成长期权（全部现值）。结论：本标的 100% 是成长期权定价，无任何资产或盈利底。

6.4 EVA/剩余收益

scripts/dcf.py 诊断输出：投入资本约 120 亿元（累计融资估算），NOPAT -32 亿元 → ROIC -26.7%，超额利差 -38.2%，当前年 EVA ≈ -32 - 11.5%×120 = -45.8 亿元/年（价值损耗速率）。自洽检验：g = 再投资率 100% × ROIIC -8% = -8%——DCF 中的正增长全部依赖回报反转或外部资本。方法论边界声明：脚本的标准 EVA 衰减模型在 NOPAT 为负时失效（输出 +748 元/股为负 NOPAT×负利差的数学假象），弃用该值，仅采信上述诊断量。

九、投资结论、反方论证与仓位

9.1 结论

内在价值判断：显著高估——综合区间 [220, 720] 港元，概率加权 407 港元，现价 1,203 港元隐含 -82%~-40%；标定由预注册规则产出（1,203 > 1.5×720）。 未来 1–3 个月市场交易方向：宽幅震荡、事件驱动、中枢略偏下——市场最可能先交易中报的 ARR→收入确认率（9 月底前）与 GLM-5.5 基准表现（8 月）；估值向 Anthropic 20x 锚回归是贯穿压力，但流动性/叙事驱动的脉冲上行（7 月曾单日 +40%）不能排除。 投资动作：规避——未持有者不参与；持有者逢反弹减持；财报可信度 B 不触发否决降级，但不确定性极高 + 标签显著高估 → 按动作矩阵为规避。不建议做空：单日 ±30–40% 波动、逼空结构（流通盘小、散户情绪化）使空头风险收益比同样恶劣。

三者为何不同：内在价值回答"值多少钱"（DCF 收敛于 400 港元量级）；市场方向回答"先交易什么"（事件与资金面主导，可能长期偏离现金流锚）；动作综合两者与赔率结构（不对称比 0.0、P(loss) 93%）。如果今天这是一笔现金：我不会按现价买入——因为获得同样的智能上限敞口，我可以在更低估值分位买到同等增长（或等待本标的回到 720 港元下方再评估），且 12 个月内三大验证事件（中报/月之暗面定价/科创板）都会给我更好的重新定价机会。
