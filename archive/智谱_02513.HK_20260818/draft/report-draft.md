## 二、业务详情

本章要点：智谱以 GLM 系列基础模型为核心，经"本地化部署（FY2025 占收入 73.7%）＋云端 MaaS API（26.3%）"双通道变现，FY2025 收入 7.243 亿元（+131.9%）。收入 92.2% 按"某一时点"确认、NRR/RPO 等订阅指标全部未披露——其经济形态是"模型授权＋项目交付＋按量 API"混合体而非订阅 SaaS，增长质量目前只能靠 B 端续约率 95%（Tier 5 单源）等薄弱口径验证。

**口径声明**：本章财务数据为 IFRS 人民币口径，单位人民币百万元（由台账人民币千元换算）；行情项为 HKD。数据截至台账对账日 2026-08-18/19；来源标注"台账 §x / C##"指向 `forensic/ledger.md` 章节/裁决编号。

### 2.1 商业模式与公司沿革

- 公司 2019-06 设立，2025-03-26 整体变更股份公司，2026-01-08 于港交所 18C（特专科技）上市，IPO 发行价 HK$116.20（台账 §0/§1，Tier 1）。
- 核心资产为 GLM 系列基础模型：2026-06 GLM-5.2 官宣（6-13 预热 / 6-15 正式，双值保留 C16）、6-17 上线并开源；API 同期提价——GLM-5-Turbo 单代 +83% 或 2025 年底以来累计 +83%，两种口径并存（C15，引用须注明）。
- 交付双线：企业级本地化部署（私有化交付＋实施，FY2025 毛利率 48.8%）与云端部署（MaaS API 按量计费，毛利率 18.9%）（台账 §2.4，Tier 1 业绩公告 2026-03-31）。
- 团队与持股：2025-12-31 正式雇员 1,094 名（业绩公告；ESG 口径 937，C09 双值未裁决）；员工持股平台慧惠 8.86%、智登 6.10%（超额配发后、2026-07 配售前基数，C06 我的推算）。
- 投入形态：FY2025 研发开支 31.804 亿元＝收入的 439%，其中算力服务费仅 1H25 即 11.451 亿元（台账 §2.1；forensic 检查四）；经营亏损 37.868 亿元。研发强度决定其依赖外部融资：上市后 IPO 含超配毛额 50.00 亿 HKD＋2026-07 配售 314.11 亿 HKD（台账 §1，资本配置细节归第四章）。

## 三、业务与竞争分析

本章要点：中国 LLM 市场处于"早期爆发＋推理价格战＋算力军备竞赛"阶段，智谱 MaaS 调用量份额 49.5% 居第一（IDC，2025），但收入口径份额仅约 7–14%（我的推算，口径受限）。护城河综合判"窄（偏弱）"——份额上升与逆势提价是正证据，92.2% 时点确认收入、云端毛利率 18.9%、无留存与生态披露是反证；宽护城河所需的财务特征（毛利稳定、正资本回报）在台账数据中不存在。

### 3.3 份额—收入口径桥（我的判断）

调用量份额 49.5% 与收入份额 7–14% 并存的三个可能解释：①调用量含免费/低价推理流量，收入贡献低；②本地化部署收入（占收入 73.7%）大概率不在"MaaS 调用量"统计口径内；③API 单价远低于私有化项目客单价。结论：调用量份额是使用量指标而非收入指标，增长与估值判断必须落在收入/ARR 口径（ARR 17 亿元，2026-03，公司口径未经审计，台账 §1）。

### 6.7 EPV / 三要素：与 ch03 护城河交叉验证

脚本输出：常态化盈利取 FY2025 经调整净亏损 −31.82 亿元 CNY（−3,608 百万 HKD，非 IFRS，SBC 558 百万 CNY 已含于亏损——SaaS 附录要求"EPV 须扣真实 SBC"经调整口径已含）。**EPV 每股 3.52**；EPV/调整后净资产 = **0.05x → 毁灭价值（ROIC<资本成本）**；资产重置底价（现金主导，逐项折算后 34,600 百万 HKD）**每股 74.31**。

### 6.8 EVA / 剩余收益：与 ch4 资本配置交叉验证

**当前态（FY2025）符号判读**：NOPAT ≈ 经营亏损 −37.87 亿元 CNY（−4,294 百万 HKD，亏损口径税≈0）＜ WACC×投入资本 → **EVA 深负：公司未赚回资本成本，当前增长由外部资本放大**。与 ch4 计分卡"再投资：差"（收入增量 +4.12 亿元 vs 经营亏损扩大 −12.48 亿元）完全一致。披露：dcf.py 的 EVA 衰减算法在 NOPAT<0、利差穿越 −WACC 时产生符号翻转（投入资本 = NOPAT/(WACC+利差) 在分母过零处爆量），故当前态 EVA 只作符号判读、不取数值——这是模块适用边界，不是数据缺失。

**2030 基准态模块运行**（正 NOPAT 下模块有效；投入资本 11,338 百万 HKD=收入/1.5 周转假设，NOPAT 2,024）：ROIC 17.9%、超额利差 +7.4%、10 年衰减至 0 → **自洽检验：g = 再投资率 45% × ROIIC 16.0% = 7.2% ≈ DCF 衰减期平均增速 7.5% ✓**（DCF 未假设超过内生增长能力的增速；若要更快，需外部资本——正是 A 股/配售路径，ch4.4）。EVA 口径价值（15,361.5 百万 HKD，2030 时点、不含净现金、未折现）低于 DCF 同期终值（46,940 百万 HKD）：**分歧归因**——EVA 模块无永续延续项且利差严格归零，是终值纪律第 3 条的更保守版本，作 DCF 的下界校验而非独立区间来源。

3. **净现金 360 亿 HKD 与消耗路径**（CFO 双值 −23.2↔−33.5 亿映射）——若 2026 中报显示年化消耗 >40 亿元（值 B 恶化）且无新融资，熊情景生存假设需重开。

监控对齐（EQ 监控清单②⑤⑧）：CFO 分类终核、SBC 摊销表、A 股受理→定价节点均会直接改写本模型参数，触发即重跑。
