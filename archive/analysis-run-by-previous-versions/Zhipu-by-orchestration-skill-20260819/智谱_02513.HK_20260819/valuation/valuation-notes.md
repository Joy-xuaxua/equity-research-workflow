## Thesis Brief（供红队攻击；v2）

- **标定标签（脚本输出原文）**：`综合区间 [65, 300] × 现价 1043.0 → **显著高估**`（P=1,043 > 1.5×H=450；标签对任意概率组合稳健：100% 牛=250.8 仍 < 450）。
- **Gap 方向**：**偏空**（维持；v1→v2 加权值 122.4→141.6，收敛但不改方向——现价仍高于区间上限 3.5 倍）。市场隐含（反向 DCF）5 年营收 CAGR +206%~+239%/年 = 所需 2030 年营收 1,958–3,264 亿元 CNY（口径无关绝对额，处于任何行业口径总量同量级或以上）；PVGO 占现价 108%（零增长价值 −86.76/股）。
- **ARR 悬置声明（红队 F1）**：2026-07 ARR ≈71 亿元 CNY（≈10 亿美元）为钛媒体+36氪+华尔街见闻+雪球多源交叉（Tier 4），**公司口径、未经审计、定义未披露**；已按 v1 预注册推翻条件执行基准迁移，但 8-31 中报原文确认前，该锚的有效性悬置——中报若证实口径含大额未签约/背书成分，v2 的基准迁移需部分回摆。
- **3 个最承重假设**（= 红队攻击面；v2 更新）：
  1. **基准 2026 收入 63.4 亿元 CNY / 5 年 CAGR +98.8%（≈全市场 P95+，预注册迁移后）**——上推证据：8-31 中报 H1 收入 ≥11.2 亿 + ARR 经审计口径证实 + IDC 份额 >55%（牛权重加大，加权值向 170–200 移动）；回摆证据：ARR 证实含未签约/背书口径或 H1 收入 <8 亿（基准回撤至 45 亿下方，加权值回 ~125 一线）。
  2. **稳态 FCF 率 16%（P60–70）**——上调证据：云端分部毛利率连续两期 >30% + 订阅 mix 上升（pre-mortem ② 兑现线，届时 ch3"窄护城河"同步重开）；下调证据：云端连续两期 <20%、总毛利率 <40%（ch3 表 3-6 阈值）、研发/收入五年后仍 >100%（稳态率降至个位数，区间下移 30–50%）。
  3. **净现金 370 亿 HKD + 消耗路径（CFO 双值 −23.2↔−33.5 亿元映射）**——恶化证据：2026 中报年化消耗 >40 亿元（超值 B 上沿）且无已确认融资；回补证据：A 股 2026Q4 前后定价落地（保守偏差回补 +20~32/股，"回 A 静默期"线索 Tier 5）。
- 标签翻转条件（诚实边界）：需要现价 < 450 才脱离"显著高估"、< 345 才脱离"高估"——即市场先跌 57–66%，或模型端出现"2030 年收入 >600 亿元 CNY + FCF 率 >20% + 留存 KPI 强劲"的证据组合（≈中国 LLM 市场垄断化 + 软件级利润率，与 ch3 窄护城河直接冲突，届时须先重开 ch3）。
